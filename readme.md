# GMT 458 – Web GIS Assignment 1

## Personal Web GIS Portfolio

This project was developed as part of the GMT 458 Web GIS course at Hacettepe University, Department of Geomatics Engineering.

The aim of this assignment is to create a personal website using HTML, CSS, JavaScript, OpenLayers, and Leaflet.

## Website Pages

- **Home:** Personal introduction and academic background.
- **Technologies:** A table containing technologies, images, and descriptions.
- **Maps & Projects:** Interactive web maps developed using OpenLayers and Leaflet.

## Web GIS Features

**1. Marker Visibility Based on Zoom Level**

To prevent marker overlap at low zoom levels, marker visibility is controlled using a zoom threshold.

In the Leaflet map, city markers appear at zoom level 6 and above and disappear at lower zoom levels.

**2. Preventing World Repetition**

The map configuration uses settings such as `wrapX: false` in OpenLayers and `noWrap: true` in Leaflet to prevent repeated world copies.

**3. Interactive Maps**

The OpenLayers map displays the Hacettepe University Beytepe Campus area.

The Leaflet map displays Ankara, Istanbul, and Izmir with interactive markers and popups.
